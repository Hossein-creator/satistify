# satistify

Persönlicher Speicherplatz für alles, was Claude schreibt und erstellt.

| Ordner | Inhalt |
|---|---|
| `notizen/` | Notizen, Ideen, Zusammenfassungen |
| `dokumente/` | längere Texte und Berichte |
| `memory/` | Kontext über Nutzer und Projekte |

Siehe `CLAUDE.md` für die Regeln, nach denen Claude hier ablegt.
